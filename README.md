# 논산대건고 선택과목 수강신청 (v2)

2026학년도 입학생이 2~3학년 선택과목을 고르고 제출하는 사이트예요.
사이트는 GitHub Pages로, 저장은 구글 시트 + Apps Script로 해요.

## 파일

| 파일 | 내용 |
|---|---|
| `index.html`, `style.css`, `app.js` | 사이트 화면 |
| `config.js` | **연결 정보** (Apps Script 주소, 구글 로그인 ID) — 주소를 바꿀 땐 이 파일만 고쳐요 |
| `curriculum.js` | 교육과정 (과목·학점·선택 규칙) |
| `apps-script/Code.gs` | 구글 시트에 붙여넣는 서버 코드 |
| `tools/sync-curriculum.js` | `curriculum.js`를 고친 뒤 `Code.gs`에 똑같이 반영해 주는 도구 |

## 처음 연결하기 (사본 시트로 테스트)

1. **시트 사본 만들기** — 원본 스프레드시트에서 `파일 → 사본 만들기`.
2. **서버 코드 넣기** — 사본에서 `확장 프로그램 → Apps Script`를 열고, 들어 있는 코드를 모두 지운 뒤
   `apps-script/Code.gs` 전체를 붙여넣고 저장해요.
   이 코드는 자기가 붙어 있는 스프레드시트(=사본)에만 읽고 써요.
3. **점검** — 사본 시트를 새로고침하면 위쪽 메뉴에 `수강신청 관리`가 생겨요.
   `① 설정 점검하기`를 눌러 연결된 시트 이름이 사본이 맞는지, 빠진 것이 없는지 확인해요.
4. **웹 앱으로 배포** — Apps Script에서 `배포 → 새 배포 → 웹 앱`.
   - 다음 사용자 인증 정보로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
   - 만들어진 `…/exec` 주소를 복사해요.
5. **사이트에 주소 넣기** — `config.js`의 `GAS_URL`에 붙여넣어요.
6. **GitHub Pages 켜기** — 저장소 `Settings → Pages → Branch: main / (root)`.
7. **구글 로그인 허용** — Google Cloud 콘솔의 OAuth 클라이언트(`config.js`의 `CLIENT_ID`)에서
   `승인된 자바스크립트 원본`에 사이트 주소(예: `https://아이디.github.io`)를 추가해요.
8. **제출 열기** — 사본의 `설정` 시트에서 `IS_OPEN`을 `TRUE`로 바꿔요.

> Code.gs를 고친 뒤에는 `배포 → 배포 관리 → 수정(연필) → 버전: 새 버전 → 배포`를 해야 반영돼요.

## 설정 시트

| A열 | B열 |
|---|---|
| `IS_OPEN` | `TRUE`면 제출 가능, `FALSE`면 닫힘 |
| `CLOSED_MESSAGE` | 닫혀 있을 때 학생에게 보여 줄 문구 |
| `OPEN_FROM` | (선택) 이 날짜·시각부터 제출 가능 |
| `OPEN_UNTIL` | (선택) 이 날짜·시각까지 제출 가능. 날짜만 쓰면 그날 밤까지 |

## 관리 메뉴 (시트 위쪽 `수강신청 관리`)

- **① 설정 점검하기** — 아무것도 바꾸지 않고 상태만 알려 줘요.
- **② 제출현황에 빠진 학생 행 추가** — 학번DB에 있는데 제출현황에 없는 학생 행을 만들어요.
- **③ 제출현황 다시 만들기** — `2026 입학 1학년` 시트의 `1` 표시를 읽어 제출현황의 2~3학년 칸을 다시 채워요.
- **④ 2026 입학 1학년 다시 채우기** — 반대로 제출현황의 과목명으로 `1` 표시를 다시 채워요.

## 알아 둘 점

- `2026 입학 1학년` 시트는 열 순서가 아니라 **1행의 학기 제목과 2행의 과목명**으로 칸을 찾아요.
  그래서 학기 사이에 "10개" 같은 열이 있거나 열 순서를 바꿔도 맞는 칸에 기록돼요.
  과목명을 바꾸면 못 찾으니, 바꾼 뒤에는 `① 설정 점검하기`로 확인해요.
- 학점 규칙(총 174, 국·수·영 81 이하, 교양 16 이상), 과목 수, 중복, 선이수 조건은 서버에서도 다시 확인해요.
- 운영 주소로 바꿀 때는 `config.js`의 `GAS_URL`만 운영 시트의 웹 앱 주소로 바꾸면 돼요.
